### `> QUEST LOG`

<details>
<summary><b>🤖 rag-ticket-intelligence</b> — the one i'm most proud of</summary>
<br/>

an AI system that reads IT support tickets and figures out how to fix them.

it retrieves similar past tickets from a vector store, reranks them with a cross-encoder, and feeds the best matches to a language model that generates a resolution. built on 10,000 synthetic tickets i generated myself — not a kaggle download, actual synthetic data with realistic distributions.

evaluated with RAGAS (faithfulness, relevance, context recall). benchmarked BGE vs OpenAI embeddings. tracked 10+ classifier experiments in MLflow. this one has depth.

`LangChain` · `ChromaDB` · `sentence-transformers` · `OpenAI` · `MLflow` · `RAGAS` · `Flask` · `Streamlit`

</details>

<details>
<summary><b>🏗️ cementStrengthPred</b> — the one that just works</summary>
<br/>

ML regression model that predicts compressive strength of cement from its mix composition. not flashy. good fundamentals. the kind of project that teaches you more about feature engineering than any tutorial.

`scikit-learn` · `Pandas` · `NumPy`

</details>

<details>
<summary><b>💰 cashCollection-A2A</b> — agents talking to agents</summary>
<br/>

agent-to-agent automation for cash collection workflows. an early experiment in building systems where AI agents coordinate with each other instead of just responding to humans.

`Python`

</details>

<details>
<summary><b>🔍 ReviewProbe</b> — the one born from frustration</summary>
<br/>

built this because i wanted to know if a product was actually good before buying it. scrapes flipkart reviews, prices, and ratings, then lets you analyse them on a clean webpage. AWS-powered backend.

`AWS` · `Python` · `CSS`

</details>
